Fixed-width iframes at true declared CSS widths (390/430/768/1280) for mobile-first verification, since this environment's window resize floor is ~960px. Each iframe loads the real built app from the same origin. On load, this page spoofs `document.hidden` / `visibilityState` to `false` on itself and every iframe document -- automation tools that drive this page in a background tab group report a genuinely hidden/backgrounded document, which pauses Chrome's rendering pipeline (rAF never fires, CSS transitions stall) for everything on the page, including the live reactbits.dev WebGL backgrounds. This does not happen for a real visitor actively scrolling; the spoof exists only so a screenshot taken through this same class of automation tooling reflects what a real, focused tab renders.
